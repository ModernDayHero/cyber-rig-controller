Modes
The lenses breathe between these, like the CLUE's color pickers.
Byte on the bus: D 0x44 CLUE: idle

Mode chips act like the CLUE menu. Each lens is its own Circuit Playground Bluefruit (RB-L and RB-R) with no wire between them: the CLUE links to both over BLE and sends each the same byte, so they stay in step, the right side mirroring the left. Audio uses a simulated 124 BPM track here; on the boards each lens listens with its own mic. The Octlet's eight legs light the byte the CLUE sends, and both lenses run the same code as leds.py.
